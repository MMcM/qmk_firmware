# Pimoroni Keybow

This keypad is meant to be used with a Raspberry Pi Zero. This definition uses an [ATMegaZero](https://atmegazero.com/) instead.

Keyboard Maintainer: [MMcM](https://github.com/MMcM)
Hardware Supported: Keybow, Keybow Mini, ATMegaZero  

Make example for this keyboard (after setting up your build environment):

    make keybow:default

Flashing example for this keyboard:

    make keybow:default:flash
