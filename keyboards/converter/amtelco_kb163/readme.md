# Amtelco KB163

A converter for the Amtelco KB163, an AT call center keyboard with _lots_ of vintage Cherry blacks.

Keyboard Maintainer: [MMcM](https://github.com/MMcM)  
Hardware Supported: KB163, Teensy  

Make example for this keyboard (after setting up your build environment):

    make converter/amtelco_kb163:default

## Hardware

Should work with any of the possible wirings for `PS2_DRIVER`.

* `usart`: Clock (pin 1) to `XCK` (`D5`) and Data (pin 2) to `RXD` (`D2`).
* `interrupt`: Clock to `D1` and Data to `D0`.
* `busywait`: Same.
