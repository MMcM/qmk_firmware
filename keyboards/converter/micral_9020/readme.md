# Micral 9020

A converter for the Bull Micral 9020 keyboard.

Keyboard Maintainer: [MMcM](https://github.com/MMcM)  
Hardware Supported: 9020, Teensy 2.0  

Make example for this keyboard (after setting up your build environment):

    make converter/micral_9020:default

## Protocol

The keyboard protocol is 600 baud TTL serial.

## Connections

A cable connects a 26-pin IDC connector on the PCB to a DE-9 male.

| IDC | Color     | DE-9 | Signal        | AVR |
|-----|-----------|------|---------------|-----|
|6,7,8|Green,Brown| 1,2  | GND           | GND |
|  9  | Black     |  3   | TX (to kbd)   | PD3 |
| 11  | Green     |  5   | PE            |     |
| 1,2 | Red, Blue | 6,7  | +5V           | +5V |
| 13  | White     |  8   | RX (from kbd) | PD2 |
